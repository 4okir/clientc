# Счётчик пердышей Димана

Общий счётчик для всех устройств. GitHub Pages обслуживает интерфейс; Worker в Sites хранит события в постоянной D1-базе.

## Поведение

- Основной итог не обнуляется по дням или при закрытии страницы.
- Нажатия имеют уникальные идентификаторы: повтор отправки не увеличивает итог дважды.
- Число увеличивается сразу, а отправка идёт пачками до 32 событий. Квитанции сервера предотвращают повторное прибавление уже сохранённых нажатий после потери ответа или перезагрузки.
- При потере сети очередь остаётся на устройстве и отправляется после возвращения связи.
- Новая очередь и кэш используют пространство v2; старые нажатия v1 сохраняются и отправляются. Подписанное устройство v1 остаётся прежним. Открытые новые вкладки координируют синхронизацию через Web Locks.
- Отмена касается только собственного события устройства. Сброса и удаления общей истории нет.
- Статистика за день использует Europe/Moscow.
- Личный рекорд за день вычисляется чтением существующей истории; достижения 10/50/100 зависят от сохранённого итога.
- Смешные фразы и звук отделены от сохранения. Четыре громких варианта пука играют сразу по нажатию «Диман выдал», звук можно выключить. Компрессор и ограничитель сдерживают пики. При открытии страницы и фоновой синхронизации звука нет.

## Разработка

`npm ci`, `npm test`, `npm run build`.

`public/` содержит интерфейс, `server.mjs` — API, `db/schema.js` и `drizzle/` — схему и миграции. `migrations/0000_init.sql` — копия начальной миграции для тестов на реальном SQLite.

`.openai/hosting.json` закрепляет постоянный project_id и D1-привязку DB. Миграции упаковываются в `dist/.openai/drizzle`, Worker — в `dist/server/index.js`.

Архив публикации создаётся командой `node scripts/package.mjs`: он сохраняет каталог `dist` и корневой manifest, включая миграции по стандартному пути плагина Sites Vite.

Секрет `COUNTER_SIGNING_KEY` настраивается через Sites и сохраняется между публикациями. Он не включается в файлы, браузер или GitHub. Браузер получает только подписанный токен своего устройства.
