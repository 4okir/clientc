# ШЛЯПА. — Мастерская настроения

Интерактивный сайт без сборки и сторонних библиотек.

## Возможности

- Четыре фасона: федора, ковбойская шляпа, панама и цилиндр.
- Восемь цветов, три ленты и три варианта освещения.
- Четыре анимации, включая конфетти; поддержка уменьшенного движения.
- Случайные образы, ссылки с сохранёнными параметрами и скачивание SVG.
- До восьми избранных образов в localStorage этого браузера.
- Тест из трёх вопросов, словарь фасонов и генератор шляпных мыслей.

## Запуск

Выполните `python3 -m http.server 8000` в папке проекта и откройте `http://localhost:8000`. HTTP-сервер необходим для загрузки SVG и JavaScript-модулей.

## Публикация

GitHub Pages: ветка `hat-site`, папка `/ (root)`. Файл `.nojekyll` отключает Jekyll. Ресурсы используют относительные пути.

Рисунки находятся в `artwork/`, дополнительные разделы — в `extras/`. Настройки и избранное сохраняются только в текущем браузере; серверной базы нет.
