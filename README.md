# Счётчик пердышей Димана

Общий счётчик для всех устройств. Подтверждённое число хранится в постоянной базе и не сбрасывается при перезагрузке, смене устройства или обновлении сайта.

Доступны +1, отмена собственного последнего нажатия, статистика за московские сутки, личный рекорд дня, достижения 10/50/100, смешные фразы и необязательный звук. Повторы запросов не считаются дважды; при потере связи очередь остаётся в браузере до отправки.

Звук выключен по умолчанию и включается пользователем. Развлекательные элементы отделены от сохранения счётчика и не могут изменять его значение.

GitHub Pages: ветка hat-site, папка / (root). API и постоянная база работают на Sites; секреты в репозиторий не включаются.
