# ШЛЯПА.

Небольшой адаптивный сайт с интерактивной шляпой: четыре цвета, лёгкое движение за курсором и приветствие по кнопке. Без сборки, сторонних библиотек и внешних шрифтов.

## Запуск

Из папки проекта выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`. HTTP-сервер нужен для загрузки SVG и его перекрашивания.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Все ресурсы используют относительные пути, поэтому сайт работает в подпапке репозитория.

Основные файлы: `index.html`, `styles.css`, `app.js`, `hat.svg`.
