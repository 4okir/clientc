# Счётчик пердышей Димана

Общий счётчик для всех посетителей. Подтверждённое число хранится в постоянной базе и не сбрасывается после закрытия страницы, смены устройства или обновления интерфейса.

Доступны +1, отмена собственного последнего нажатия, статистика за московские сутки и очередь повторной отправки при потере сети. Каждое событие имеет уникальный ID; повторы не считаются дважды.

GitHub Pages: ветка hat-site, папка / (root). Интерфейс обращается к API на Sites; серверный ключ в этот репозиторий не включается.
