# Счётчик пердышей Димана

Общий счётчик с постоянным хранением значения. Нажатия сохраняются в общей базе; обновление страницы и смена устройства не сбрасывают итог.

Кнопка «Диман выдал» сразу проигрывает один из четырёх коротких звуков пука. Звук можно выключить; выбор запоминается. При открытии страницы, фоновой синхронизации и повторном подтверждении звук не играет. Аудио не влияет на сохранение нажатий.

Также доступны отмена собственного события, статистика за московские сутки, рекорд дня, достижения 10/50/100 и смешные фразы.

GitHub Pages: ветка hat-site, папка / (root). API и постоянная база работают на Sites.
